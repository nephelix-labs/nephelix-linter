### Privacy by Design

**Nephelix Linter** is a CLI tool that helps developers stop data leaks before they reach production. It tells you when you install packages that  telemetry/tracking (like certain analytics libraries), Flags API keys or passwords committed to Git, Auto-generates secure HTTP headers for Express/Next.js/Nginx configs,  Automatically redacts emails/IPs from console.log() statements in production builds e.t.c, with more features coming...
